# Ploceus Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Paper plugin that groups Multiverse worlds into projects with authors, tags, descriptions and an audit trail, loads worlds on demand instead of at boot, and exposes the whole workflow through the Paper Dialog API.

**Architecture:** Single Gradle module, package layers enforced by an ArchUnit test. Multiverse stays the owner of world lifecycle; Ploceus stores membership and metadata in Hibernate and calls the Multiverse API for actions. One `ProjectUi` interface with three interchangeable channels (dialog, inventory, chat), picked per player by client protocol version.

**Tech Stack:** Java 25, Paper 26.2, Multiverse-Core 5.8.1, Hibernate ORM 7, HikariCP, Liquibase, H2/PostgreSQL, Guice, Cloud 2.0.0, InventoryFramework 0.12.1, Datafaker 2.7.0, Adventure 5.2.0.

**Spec:** `docs/superpowers/specs/2026-09-13-ploceus-design.md`

## Global Constraints

Every task's requirements implicitly include this section.

- **Java 25**, `options.release.set(25)`. **No preview features** — the server must not need `--enable-preview`.
- **Gradle group** `net.onelitefeather`, **rootProject.name** `Ploceus`, root package `net.onelitefeather.ploceus`.
- **Version** in `gradle.properties` marked `# x-release-please-version`.
- **Adventure Key namespace is fixed to `ploceus`.** Users type only the value.
- **`domain` imports nothing** — no Bukkit, no Multiverse, no Hibernate, no Vavr.
- **`service` must not import `ui`.** The dependency runs from `ui` to `service`, never back.
- **The three UI channels must not import each other.**
- **All database access is asynchronous**, off the main thread. Results return to the main thread before any Bukkit call.
- **All user-facing text is MiniMessage**, defined in `Messages`. Never hardcode a string in a UI class.
- **Commits follow Conventional Commits** (`feat:`, `fix:`, `test:`, `chore:`, `docs:`). Trunk-based on `main`, short-lived `feat/` branches, squash merge.
- **Never add Claude attribution** to commits or pull requests.

**Multiverse dependency — read this before Step 1.**
Multiverse-Core 5.8.1 is **not** on Maven Central (the `org.multiverse:multiverse-core` artifact there is an unrelated STM library), JitPack only carries up to 4.3.16, and `repo.mvplugins.org` returns 404. Two routes, in order of preference:

1. **Mirror it into the org's Reposilite** (`https://repo.onelitefeather.dev/releases`), which the org already runs, then depend on `org.mvplugins.multiverse.core:multiverse-core:5.8.1` normally. Do this once; every later build and CI run then works unchanged.
2. **Interim:** copy `multiverse-core-5.8.1.jar` from the server into `libs/` and use `compileOnly(files("libs/multiverse-core-5.8.1.jar"))`. This unblocks local work but **breaks CI**, so route 1 must happen before the first pull request.

```java
package net.onelitefeather.ploceus;

import io.papermc.paper.plugin.bootstrap.BootstrapContext;
import io.papermc.paper.plugin.bootstrap.PluginBootstrap;
import io.papermc.paper.plugin.loader.PluginClasspathBuilder;
import io.papermc.paper.plugin.loader.PluginLoader;
import io.papermc.paper.plugin.loader.library.impl.MavenLibraryResolver;
import org.eclipse.aether.artifact.DefaultArtifact;
import org.eclipse.aether.graph.Dependency;
import org.eclipse.aether.repository.RemoteRepository;
import org.jetbrains.annotations.NotNull;

public final class PloceusBootstrap implements PluginBootstrap, PluginLoader {

    private static final String CENTRAL = "https://repo.maven.apache.org/maven2/";

    private static final String[] RUNTIME_LIBRARIES = {
            "org.hibernate.orm:hibernate-core:7.4.8.Final",
            "com.zaxxer:HikariCP:7.1.0",
            "org.liquibase:liquibase-core:5.0.4",
            "com.h2database:h2:2.5.250",
            "org.postgresql:postgresql:42.7.13"
    };

    @Override
    public void bootstrap(@NotNull BootstrapContext context) {
        // Nothing to do yet; kept so later tasks have a hook before the server starts.
    }

    @Override
    public void classloader(@NotNull PluginClasspathBuilder classpathBuilder) {
        MavenLibraryResolver resolver = new MavenLibraryResolver();
        resolver.addRepository(new RemoteRepository.Builder("central", "default", CENTRAL).build());
        for (String coordinate : RUNTIME_LIBRARIES) {
            resolver.addDependency(new Dependency(new DefaultArtifact(coordinate), null));
        }
        classpathBuilder.addLibrary(resolver);
    }
}
```

The one place that knows the `ploceus` namespace and how a Multiverse world name becomes a key. Everything downstream depends on it, so it is built first and test-first.

**Interfaces:**
- Consumes: Adventure `net.kyori.adventure.key.Key` (supplied by paper-api).
- Produces:

  - `key()` → `Key`, `value()` → `String`, `asString()` → `String`
  - constant `PloceusKey.NAMESPACE = "ploceus"`

- [ ] **Step 3: Write the implementation**

A record, so equality is value-based for free.

```java
package net.onelitefeather.ploceus.domain;

import net.kyori.adventure.key.Key;
import net.kyori.adventure.key.Keyed;

/// Identity of every addressable Ploceus entity.
///
/// The namespace is fixed: users type only the value, and the namespace is prepended here.
public record PloceusKey(Key key) implements Keyed, Comparable<PloceusKey> {

    public static final String NAMESPACE = "ploceus";

    public PloceusKey {
        if (!NAMESPACE.equals(key.namespace())) {
            throw new IllegalArgumentException(
                    "Expected namespace '" + NAMESPACE + "' but got '" + key.namespace() + "'");
        }
    }

    public static PloceusKey of(String value) {
        if (!isValidValue(value)) {
            throw new IllegalArgumentException("Not a valid key value: '" + value + "'");
        }
        return new PloceusKey(Key.key(NAMESPACE, value));
    }

    /// Derives a key from a Multiverse world name. Never throws: illegal characters
    /// become '_' so that every existing world can be imported.
    public static PloceusKey fromWorldName(String worldName) {
        StringBuilder builder = new StringBuilder(worldName.length());
        for (char c : worldName.toLowerCase(java.util.Locale.ROOT).toCharArray()) {
            builder.append(Key.allowedInValue(c) ? c : '_');
        }
        String value = builder.isEmpty() ? "world" : builder.toString();
        return of(value);
    }

    public static PloceusKey parse(String stored) {
        return new PloceusKey(Key.key(stored));
    }

    public static boolean isValidValue(String value) {
        return value != null && !value.isEmpty() && Key.parseableValue(value);
    }

    public String value() {
        return key.value();
    }

    public String asString() {
        return key.asString();
    }

    @Override
    public int compareTo(PloceusKey other) {
        return key.compareTo(other.key);
    }

    @Override
    public String toString() {
        return asString();
    }
}
```

```java
package net.onelitefeather.ploceus.domain;

import java.util.function.Function;

/// The only result type services return. `messageKey` addresses a MiniMessage entry in
/// `Messages`; `detail` is for the log, never for the player.
public sealed interface OperationResult<T> {

    record Success<T>(T value) implements OperationResult<T> {}

    record Failure<T>(String messageKey, String detail) implements OperationResult<T> {}

    static <T> OperationResult<T> success(T value) {
        return new Success<>(value);
    }

    static <T> OperationResult<T> failure(String messageKey, String detail) {
        return new Failure<>(messageKey, detail);
    }

    default boolean isSuccess() {
        return this instanceof Success<T>;
    }

    default T orElse(T fallback) {
        return switch (this) {
            case Success<T> success -> success.value();
            case Failure<T> ignored -> fallback;
        };
    }

    default <R> OperationResult<R> map(Function<T, R> mapper) {
        return switch (this) {
            case Success<T> success -> success(mapper.apply(success.value()));
            case Failure<T> failure -> failure(failure.messageKey(), failure.detail());
        };
    }
}
```

- [ ] **Step 6: Write `HibernateBootstrap`**

**This is the classloader pitfall from the spec.** Hibernate and Liquibase both resolve
services through the thread context classloader. Inside a Bukkit plugin that classloader
belongs to the server, not to the plugin, so dialect and changelog resolution fail with
confusing errors. Set it around construction and always restore it in a `finally`.

```java
package net.onelitefeather.ploceus.persistence;

import com.zaxxer.hikari.HikariConfig;
import com.zaxxer.hikari.HikariDataSource;
import liquibase.Liquibase;
import liquibase.database.DatabaseFactory;
import liquibase.database.jvm.JdbcConnection;
import liquibase.resource.ClassLoaderResourceAccessor;
import net.onelitefeather.ploceus.domain.*;
import org.hibernate.SessionFactory;
import org.hibernate.cfg.Configuration;

import java.sql.Connection;
import java.util.Map;

public final class HibernateBootstrap {

    private static final String CHANGELOG = "db/changelog/db.changelog-master.xml";

    private HibernateBootstrap() { }

    public static HikariDataSource dataSource(DatabaseConfig config) {
        HikariConfig hikari = new HikariConfig();
        hikari.setJdbcUrl(config.jdbcUrl());
        hikari.setUsername(config.user());
        hikari.setPassword(config.password());
        hikari.setDriverClassName(config.driverClass());
        hikari.setMaximumPoolSize(config.poolSize());
        hikari.setPoolName("ploceus-pool");
        return new HikariDataSource(hikari);
    }

    /// Applies pending Liquibase changesets. Must run before {@link #create}, because
    /// Hibernate is configured to validate rather than create the schema.
    public static void migrate(HikariDataSource dataSource, ClassLoader pluginClassLoader) {
        withClassLoader(pluginClassLoader, () -> {
            try (Connection connection = dataSource.getConnection()) {
                var database = DatabaseFactory.getInstance()
                        .findCorrectDatabaseImplementation(new JdbcConnection(connection));
                try (Liquibase liquibase = new Liquibase(
                        CHANGELOG, new ClassLoaderResourceAccessor(pluginClassLoader), database)) {
                    liquibase.update("");
                }
            } catch (Exception exception) {
                throw new IllegalStateException("Ploceus schema migration failed", exception);
            }
            return null;
        });
    }

    public static SessionFactory create(DatabaseConfig config, HikariDataSource dataSource,
                                        ClassLoader pluginClassLoader) {
        return withClassLoader(pluginClassLoader, () -> new Configuration()
                .addAnnotatedClass(Project.class)
                .addAnnotatedClass(ProjectWorld.class)
                .addAnnotatedClass(Tag.class)
                .addAnnotatedClass(AuditEntry.class)
                .addAttributeConverter(KeyAttributeConverter.class)
                .addProperties(properties(config))
                .setProperty("hibernate.connection.datasource", dataSource)
                .buildSessionFactory());
    }

    private static java.util.Properties properties(DatabaseConfig config) {
        java.util.Properties properties = new java.util.Properties();
        Map.of(
                "hibernate.dialect", config.hibernateDialect(),
                "hibernate.hbm2ddl.auto", "validate",
                "hibernate.show_sql", "false",
                "hibernate.format_sql", "false",
                "hibernate.jdbc.batch_size", "32",
                "hibernate.order_updates", "true"
        ).forEach(properties::setProperty);
        return properties;
    }

    private static <T> T withClassLoader(ClassLoader classLoader, java.util.function.Supplier<T> action) {
        Thread current = Thread.currentThread();
        ClassLoader previous = current.getContextClassLoader();
        current.setContextClassLoader(classLoader);
        try {
            return action.get();
        } finally {
            current.setContextClassLoader(previous);
        }
    }
}
```

```java
package net.onelitefeather.ploceus.persistence;

import net.onelitefeather.ploceus.domain.PloceusKey;
import net.onelitefeather.ploceus.domain.Project;
import org.hibernate.SessionFactory;

import java.util.List;
import java.util.Optional;

public class ProjectRepository {

    private final SessionFactory sessionFactory;

    public ProjectRepository(SessionFactory sessionFactory) {
        this.sessionFactory = sessionFactory;
    }

    public Optional<Project> findByKey(PloceusKey key) {
        return sessionFactory.fromSession(session ->
                Optional.ofNullable(session.find(Project.class, key)));
    }

    public List<Project> findAll() {
        return sessionFactory.fromSession(session -> session
                .createQuery("from Project order by displayName", Project.class)
                .getResultList());
    }

    /// Case-insensitive match against key, display name, description and tag key.
    public List<Project> search(String term) {
        String pattern = "%" + term.toLowerCase(java.util.Locale.ROOT) + "%";
        return sessionFactory.fromSession(session -> session.createQuery("""
                        select distinct p from Project p
                        left join p.tags t
                        where lower(p.displayName) like :pattern
                           or lower(p.description) like :pattern
                           or lower(str(p.key)) like :pattern
                           or lower(str(t.key)) like :pattern
                        order by p.displayName
                        """, Project.class)
                .setParameter("pattern", pattern)
                .getResultList());
    }

    public void save(Project project) {
        sessionFactory.inTransaction(session -> session.merge(project));
    }

    public void delete(Project project) {
        sessionFactory.inTransaction(session -> session.remove(session.merge(project)));
    }
}
```

- [ ] **Step 4: Write `SchedulerAdapter`**

Database work runs on virtual threads; anything touching Bukkit hops back to the main
thread. Isolating this makes services testable with a synchronous stub.

```java
package net.onelitefeather.ploceus.platform;

import org.bukkit.plugin.Plugin;
import org.bukkit.scheduler.BukkitTask;

import java.util.concurrent.CompletableFuture;
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;
import java.util.function.Supplier;

public class SchedulerAdapter implements AutoCloseable {

    private final Plugin plugin;
    private final ExecutorService executor = Executors.newVirtualThreadPerTaskExecutor();

    public SchedulerAdapter(Plugin plugin) {
        this.plugin = plugin;
    }

    public void async(Runnable work) {
        executor.execute(work);
    }

    public <T> CompletableFuture<T> supplyAsync(Supplier<T> work) {
        return CompletableFuture.supplyAsync(work, executor);
    }

    /// Hops back onto the main thread. Every Bukkit call must go through here.
    public void sync(Runnable work) {
        if (plugin.getServer().isPrimaryThread()) {
            work.run();
        } else {
            plugin.getServer().getScheduler().runTask(plugin, work);
        }
    }

    public AutoCloseable repeating(Runnable work, long initialDelayTicks, long periodTicks) {
        BukkitTask task = plugin.getServer().getScheduler()
                .runTaskTimer(plugin, work, initialDelayTicks, periodTicks);
        return task::cancel;
    }

    @Override
    public void close() {
        executor.shutdown();
    }
}
```

```java
package net.onelitefeather.ploceus.platform;

import net.onelitefeather.ploceus.domain.OperationResult;
import net.onelitefeather.ploceus.domain.PloceusKey;
import org.bukkit.NamespacedKey;
import org.bukkit.World;
import org.bukkit.entity.Player;
import org.mvplugins.multiverse.core.MultiverseCoreApi;
import org.mvplugins.multiverse.core.world.MultiverseWorld;
import org.mvplugins.multiverse.core.world.WorldManager;
import org.mvplugins.multiverse.core.world.generators.GeneratorProvider;
import org.mvplugins.multiverse.core.world.options.CreateWorldOptions;
import org.mvplugins.multiverse.core.world.options.UnloadWorldOptions;

import java.util.ArrayList;
import java.util.List;
import java.util.concurrent.CompletableFuture;

public class MultiverseAdapter {

    private final MultiverseCoreApi api;
    private final SchedulerAdapter scheduler;

    public MultiverseAdapter(MultiverseCoreApi api, SchedulerAdapter scheduler) {
        this.api = api;
        this.scheduler = scheduler;
    }

    private WorldManager worldManager() {
        return api.getWorldManager();
    }

    /// Must be called on the main thread. The returned snapshots are immutable and safe
    /// to hand to the async executor afterwards.
    public List<WorldSnapshot> snapshotAll() {
        List<WorldSnapshot> snapshots = new ArrayList<>();
        for (MultiverseWorld world : worldManager().getWorlds()) {
            String name = world.getName();
            boolean loaded = worldManager().isLoadedWorld(name);
            snapshots.add(new WorldSnapshot(name, PloceusKey.fromWorldName(name), loaded,
                    world.isAutoLoad(), world.getAlias(), playerCount(name)));
        }
        return List.copyOf(snapshots);
    }

    public int playerCount(String worldName) {
        World world = org.bukkit.Bukkit.getWorld(worldName);
        return world == null ? 0 : world.getPlayers().size();
    }

    public boolean isLoaded(String worldName) {
        return worldManager().isLoadedWorld(worldName);
    }

    public OperationResult<Void> load(String worldName) {
        var attempt = worldManager().loadWorld(worldName);
        return attempt.isSuccess()
                ? OperationResult.success(null)
                : OperationResult.failure("world.load.failed", String.valueOf(attempt.getFailureReason()));
    }

    public OperationResult<Void> unload(String worldName) {
        var world = worldManager().getWorld(worldName);
        if (world.isEmpty()) {
            return OperationResult.failure("world.unknown", worldName);
        }
        var attempt = worldManager().unloadWorld(UnloadWorldOptions.world(
                worldManager().getLoadedWorld(worldName).get()));
        return attempt.isSuccess()
                ? OperationResult.success(null)
                : OperationResult.failure("world.unload.failed", String.valueOf(attempt.getFailureReason()));
    }

    public OperationResult<Void> setAutoLoad(String worldName, boolean autoLoad) {
        var world = worldManager().getWorld(worldName);
        if (world.isEmpty()) {
            return OperationResult.failure("world.unknown", worldName);
        }
        var result = world.get().setAutoLoad(autoLoad);
        return result.isSuccess()
                ? OperationResult.success(null)
                : OperationResult.failure("world.autoload.failed", String.valueOf(result.getCause()));
    }

    public OperationResult<Void> setAlias(String worldName, String alias) {
        var world = worldManager().getWorld(worldName);
        if (world.isEmpty()) {
            return OperationResult.failure("world.unknown", worldName);
        }
        var result = world.get().setAlias(alias);
        return result.isSuccess()
                ? OperationResult.success(null)
                : OperationResult.failure("world.alias.failed", String.valueOf(result.getCause()));
    }

    public OperationResult<String> createWorld(WorldCreationRequest request) {
        CreateWorldOptions options = CreateWorldOptions
                .worldKey(new NamespacedKey(PloceusKey.NAMESPACE, request.key().value()))
                .environment(World.Environment.valueOf(request.environment()))
                .generateStructures(request.generateStructures());

        if (request.generator() != null && !request.generator().isBlank()) {
            options = options.generator(request.generator());
        }
        if (request.generatorSettings() != null && !request.generatorSettings().isBlank()) {
            options = options.generatorSettings(request.generatorSettings());
        }
        if (request.biome() != null && !request.biome().isBlank()) {
            options = options.biome(request.biome());
        }
        if (request.seed() != null) {
            options = options.seed(request.seed());
        }

        var attempt = worldManager().createWorld(options);
        return attempt.isSuccess()
                ? OperationResult.success(request.worldName())
                : OperationResult.failure("world.create.failed", String.valueOf(attempt.getFailureReason()));
    }

    /// Loads the world first if necessary, then teleports through Multiverse's own safety
    /// teleporter so the player never lands inside a block.
    public CompletableFuture<OperationResult<Void>> teleport(Player player, String worldName) {
        CompletableFuture<OperationResult<Void>> future = new CompletableFuture<>();
        scheduler.sync(() -> {
            if (!isLoaded(worldName)) {
                OperationResult<Void> loadResult = load(worldName);
                if (!loadResult.isSuccess()) {
                    future.complete(loadResult);
                    return;
                }
            }
            World world = org.bukkit.Bukkit.getWorld(worldName);
            if (world == null) {
                future.complete(OperationResult.failure("world.unknown", worldName));
                return;
            }
            api.getSafetyTeleporter()
                    .to(world.getSpawnLocation())
                    .teleport(player);
            future.complete(OperationResult.success(null));
        });
        return future;
    }

    /// Populates the generator picker. VoidGen and anything else installed appears here by
    /// itself — nothing is hardcoded.
    public List<GeneratorOption> generators() {
        GeneratorProvider provider = api.getGeneratorProvider();
        List<GeneratorOption> options = new ArrayList<>();
        provider.getRegisteredGeneratorPlugins().forEach(plugin -> {
            String name = plugin.getPluginName();
            options.add(new GeneratorOption(name, List.copyOf(provider.suggestGeneratorString(name))));
        });
        return List.copyOf(options);
    }
}
```

```java
package net.onelitefeather.ploceus.service;

import net.onelitefeather.ploceus.domain.*;
import net.onelitefeather.ploceus.persistence.ProjectRepository;
import net.onelitefeather.ploceus.persistence.TagRepository;

import java.util.List;
import java.util.Optional;
import java.util.UUID;

import static net.onelitefeather.ploceus.domain.AuditEntry.TargetType.PROJECT;

public class ProjectService {

    private final ProjectRepository projects;
    private final TagRepository tags;
    private final AuditService audit;

    public ProjectService(ProjectRepository projects, TagRepository tags, AuditService audit) {
        this.projects = projects;
        this.tags = tags;
        this.audit = audit;
    }

    public Optional<Project> find(PloceusKey key) {
        return projects.findByKey(key);
    }

    public List<Project> all() {
        return projects.findAll();
    }

    public List<Project> search(String term) {
        return projects.search(term);
    }

    public OperationResult<Project> create(PloceusKey key, String displayName, Actor actor) {
        if (projects.findByKey(key).isPresent()) {
            return OperationResult.failure("project.exists", key.asString());
        }
        Project project = new Project(key, displayName);
        project.setCreatedBy(actor.uuid());
        project.setUpdatedBy(actor.uuid());
        projects.save(project);
        audit.recordEvent(PROJECT, key, actor, AuditAction.PROJECT_CREATED, displayName);
        return OperationResult.success(project);
    }

    public OperationResult<Project> rename(PloceusKey key, String displayName, Actor actor) {
        return mutate(key, actor, project -> {
            String old = project.getDisplayName();
            project.setDisplayName(displayName);
            audit.recordChange(PROJECT, key, actor, AuditAction.PROJECT_UPDATED,
                    "displayName", old, displayName);
        });
    }

    public OperationResult<Project> describe(PloceusKey key, String description, Actor actor) {
        return mutate(key, actor, project -> {
            String old = project.getDescription();
            project.setDescription(description);
            audit.recordChange(PROJECT, key, actor, AuditAction.PROJECT_UPDATED,
                    "description", old, description);
        });
    }

    public OperationResult<Project> setStatus(PloceusKey key, ProjectStatus status, Actor actor) {
        return mutate(key, actor, project -> {
            String old = project.getStatus().name();
            project.setStatus(status);
            audit.recordChange(PROJECT, key, actor, AuditAction.PROJECT_UPDATED,
                    "status", old, status.name());
        });
    }

    public OperationResult<Project> setWorldDefaults(PloceusKey key, WorldDefaults defaults, Actor actor) {
        return mutate(key, actor, project -> {
            project.setWorldDefaults(defaults);
            audit.recordEvent(PROJECT, key, actor, AuditAction.PROJECT_UPDATED,
                    "worldDefaults=" + defaults.getGenerator());
        });
    }

    public OperationResult<Project> addTag(PloceusKey projectKey, PloceusKey tagKey, Actor actor) {
        return mutate(projectKey, actor, project -> {
            project.addTag(tags.findOrCreate(tagKey));
            audit.recordEvent(PROJECT, projectKey, actor, AuditAction.TAG_ADDED, tagKey.asString());
```

```java
package net.onelitefeather.ploceus.service;

import net.onelitefeather.ploceus.domain.*;
import net.onelitefeather.ploceus.persistence.WorldRepository;
import net.onelitefeather.ploceus.platform.WorldSnapshot;

import java.util.List;

import static net.onelitefeather.ploceus.domain.AuditEntry.TargetType.WORLD;

/// Brings existing Multiverse worlds under Ploceus without guessing their grouping:
/// every unknown world becomes an unassigned entry.
public class WorldImportService {

    public record ImportSummary(int imported, int alreadyKnown, int keyCollisions) { }

    private final WorldRepository worlds;
    private final AuditService audit;

    public WorldImportService(WorldRepository worlds, AuditService audit) {
        this.worlds = worlds;
        this.audit = audit;
    }

    public ImportSummary importAll(List<WorldSnapshot> snapshots, Actor actor) {
        int imported = 0;
        int alreadyKnown = 0;
        int collisions = 0;

        for (WorldSnapshot snapshot : snapshots) {
            if (worlds.findByWorldName(snapshot.worldName()).isPresent()) {
                alreadyKnown++;
                continue;
            }
            PloceusKey key = snapshot.derivedKey();
            if (worlds.findByKey(key).isPresent()) {
                key = nextFreeKey(key);
                collisions++;
            }
            ProjectWorld world = new ProjectWorld(key, snapshot.worldName());
            if (snapshot.alias() != null && !snapshot.alias().isBlank()) {
                world.setDisplayName(snapshot.alias());
            }
            world.setCreatedBy(actor.uuid());
            world.setUpdatedBy(actor.uuid());
            worlds.save(world);
            audit.recordEvent(WORLD, key, actor, AuditAction.WORLD_IMPORTED, snapshot.worldName());
            imported++;
        }
        return new ImportSummary(imported, alreadyKnown, collisions);
    }

    private PloceusKey nextFreeKey(PloceusKey base) {
        for (int suffix = 2; suffix < 1000; suffix++) {
            PloceusKey candidate = PloceusKey.of(base.value() + "-" + suffix);
            if (worlds.findByKey(candidate).isEmpty()) {
                return candidate;
            }
        }
        throw new IllegalStateException("No free key for " + base.asString() + " after 1000 attempts");
    }
}
```

```java
            if (!alias.isSuccess()) {
                return OperationResult.failure("world.alias.failed", world.getWorldName());
```

```java
package net.onelitefeather.ploceus;

import com.google.inject.Guice;
import com.google.inject.Injector;
import com.zaxxer.hikari.HikariDataSource;
import net.onelitefeather.ploceus.di.PloceusModule;
import net.onelitefeather.ploceus.domain.Actor;
import net.onelitefeather.ploceus.persistence.HibernateBootstrap;
import net.onelitefeather.ploceus.platform.MultiverseAdapter;
import net.onelitefeather.ploceus.platform.SchedulerAdapter;
import net.onelitefeather.ploceus.platform.WorldSnapshot;
import net.onelitefeather.ploceus.service.WorldImportService;
import org.bukkit.plugin.java.JavaPlugin;
import org.hibernate.SessionFactory;
import org.mvplugins.multiverse.core.MultiverseCoreApi;

import java.util.List;

public final class PloceusPlugin extends JavaPlugin {

    private HikariDataSource dataSource;
    private SessionFactory sessionFactory;
    private SchedulerAdapter scheduler;
    private Injector injector;

    @Override
    public void onEnable() {
        saveDefaultConfig();
        PloceusConfig config = PloceusConfig.load(getConfig(), getDataFolder().toPath());

        ClassLoader pluginClassLoader = getClass().getClassLoader();
        dataSource = HibernateBootstrap.dataSource(config.database());
        HibernateBootstrap.migrate(dataSource, pluginClassLoader);
        sessionFactory = HibernateBootstrap.create(config.database(), dataSource, pluginClassLoader);

        MultiverseCoreApi.whenLoaded(api -> {
            injector = Guice.createInjector(
                    new PloceusModule(this, config, sessionFactory, dataSource, api));
            scheduler = injector.getInstance(SchedulerAdapter.class);
            importExistingWorlds();
            getLogger().info("Ploceus enabled");
        });
    }

    /// Snapshot on the main thread, import off it. Auto-load is disabled afterwards, which
    /// only takes effect from the next server start — Multiverse loads its worlds before
    /// this plugin is enabled.
    private void importExistingWorlds() {
        MultiverseAdapter multiverse = injector.getInstance(MultiverseAdapter.class);
        WorldImportService importService = injector.getInstance(WorldImportService.class);

        List<WorldSnapshot> snapshots = multiverse.snapshotAll();
        scheduler.async(() -> {
            var summary = importService.importAll(snapshots, Actor.CONSOLE);
            getLogger().info("Imported %d worlds, %d already known, %d key collisions"
                    .formatted(summary.imported(), summary.alreadyKnown(), summary.keyCollisions()));

            scheduler.sync(() -> {
                int suppressed = 0;
                for (WorldSnapshot snapshot : snapshots) {
                    if (snapshot.autoLoad() && multiverse.setAutoLoad(snapshot.worldName(), false).isSuccess()) {
                        suppressed++;
                    }
                }
                if (suppressed > 0) {
                    getLogger().info(("Disabled auto-load for %d worlds. "
                            + "This takes effect from the next server start.").formatted(suppressed));
                }
            });
        });
    }

    @Override
    public void onDisable() {
        if (scheduler != null) {
            scheduler.close();
        }
        if (sessionFactory != null) {
            sessionFactory.close();
        }
        if (dataSource != null) {
            dataSource.close();
        }
        getLogger().info("Ploceus disabled");
    }

    public Injector injector() {
        return injector;
    }
}
```

```java
package net.onelitefeather.ploceus.service;

import net.onelitefeather.ploceus.domain.PloceusKey;
import net.onelitefeather.ploceus.persistence.WorldRepository;
import net.onelitefeather.ploceus.platform.SchedulerAdapter;

import java.time.Instant;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;

/// Buffers world visits in memory and writes them in one batch per interval.
public class VisitTracker implements AutoCloseable {

    private final WorldRepository worlds;
    private final SchedulerAdapter scheduler;
    private final Map<PloceusKey, Instant> pending = new ConcurrentHashMap<>();
    private AutoCloseable task;

    public VisitTracker(WorldRepository worlds, SchedulerAdapter scheduler) {
        this.worlds = worlds;
        this.scheduler = scheduler;
    }

    /// Worlds Ploceus does not know are silently ignored.
    public void recordVisit(String worldName, Instant at) {
        worlds.findByWorldName(worldName).ifPresent(world ->
                pending.merge(world.getKey(), at, (existing, candidate) ->
                        candidate.isAfter(existing) ? candidate : existing));
    }

    public int pendingCount() {
        return pending.size();
    }

    public void flush() {
        if (pending.isEmpty()) {
            return;
        }
        Map<PloceusKey, Instant> batch = Map.copyOf(pending);
        pending.clear();
        worlds.updateLastVisited(batch);
    }

    public void start(int flushSeconds) {
        long ticks = flushSeconds * 20L;
        task = scheduler.repeating(() -> scheduler.async(this::flush), ticks, ticks);
    }

    @Override
    public void close() {
        if (task != null) {
            try {
                task.close();
            } catch (Exception ignored) {
                // cancelling a Bukkit task cannot fail meaningfully
            }
        }
        flush();
    }
}
```

```java
package net.onelitefeather.ploceus.service;

import net.onelitefeather.ploceus.domain.ProjectWorld;
import net.onelitefeather.ploceus.platform.WorldSnapshot;

import java.time.Duration;
import java.time.Instant;
import java.util.Set;

/// Pure decision function: no Bukkit, no database, no clock of its own.
public record UnloadPolicy(int defaultIdleMinutes, Set<String> neverUnload, String serverDefaultWorld) {

    public boolean shouldUnload(WorldSnapshot snapshot, ProjectWorld world, Instant now) {
        if (!snapshot.isIdle()) {
            return false;
        }
        if (world.isPinned()) {
            return false;
        }
        if (neverUnload.contains(snapshot.worldName())) {
            return false;
        }
        if (snapshot.worldName().equals(serverDefaultWorld)) {
            return false;
        }
        Instant lastVisited = world.getLastVisitedAt();
        if (lastVisited == null) {
            return true;
        }
        int minutes = world.getIdleUnloadMinutes() == null
                ? defaultIdleMinutes
                : world.getIdleUnloadMinutes();
        return Duration.between(lastVisited, now).toMinutes() >= minutes;
    }
}
```

```java
package net.onelitefeather.ploceus.service;

import net.onelitefeather.ploceus.PloceusConfig;
import net.onelitefeather.ploceus.domain.OperationResult;
import net.onelitefeather.ploceus.domain.ProjectWorld;
import net.onelitefeather.ploceus.persistence.WorldRepository;
import net.onelitefeather.ploceus.platform.MultiverseAdapter;
import net.onelitefeather.ploceus.platform.SchedulerAdapter;
import net.onelitefeather.ploceus.platform.WorldSnapshot;
import org.bukkit.entity.Player;

import java.time.Instant;
import java.util.ArrayList;
import java.util.List;
import java.util.Optional;
import java.util.concurrent.CompletableFuture;

public class WorldLifecycleService implements AutoCloseable {

    private final MultiverseAdapter multiverse;
    private final WorldRepository worlds;
    private final SchedulerAdapter scheduler;
    private final VisitTracker visits;
    private final UnloadPolicy policy;
    private final PloceusConfig config;
    private AutoCloseable reaperTask;

    public WorldLifecycleService(MultiverseAdapter multiverse, WorldRepository worlds,
                                 SchedulerAdapter scheduler, VisitTracker visits,
                                 UnloadPolicy policy, PloceusConfig config) {
        this.multiverse = multiverse;
        this.worlds = worlds;
        this.scheduler = scheduler;
        this.visits = visits;
        this.policy = policy;
        this.config = config;
    }

    /// Main thread only. Loading an already-loaded world is a no-op success.
    public OperationResult<Void> ensureLoaded(String worldName) {
        return multiverse.isLoaded(worldName)
                ? OperationResult.success(null)
                : multiverse.load(worldName);
    }

    public CompletableFuture<OperationResult<Void>> teleport(Player player, ProjectWorld world) {
        visits.recordVisit(world.getWorldName(), Instant.now());
        return multiverse.teleport(player, world.getWorldName());
    }

    /// Returns how many worlds were unloaded. Call from the main thread.
    public int runReaper() {
        List<WorldSnapshot> snapshots = multiverse.snapshotAll();
        Instant now = Instant.now();
        int unloaded = 0;
        List<String> candidates = new ArrayList<>();

        for (WorldSnapshot snapshot : snapshots) {
            if (!snapshot.isIdle()) {
                continue;
            }
            Optional<ProjectWorld> known = worlds.findByWorldName(snapshot.worldName());
            if (known.isPresent() && policy.shouldUnload(snapshot, known.get(), now)) {
                candidates.add(snapshot.worldName());
            }
        }
        for (String worldName : candidates) {
            if (multiverse.unload(worldName).isSuccess()) {
                unloaded++;
            }
        }
        return unloaded;
    }

    public void start() {
        visits.start(config.visitFlushSeconds());
        long ticks = config.reaperIntervalSeconds() * 20L;
        reaperTask = scheduler.repeating(this::runReaper, ticks, ticks);
    }

    @Override
    public void close() {
        if (reaperTask != null) {
            try {
                reaperTask.close();
            } catch (Exception ignored) {
                // cancelling a Bukkit task cannot fail meaningfully
            }
        }
        visits.close();
    }
}
```

**Threading note for the implementer:** `runReaper` calls `worlds.findByWorldName`, which
hits the database, from the main thread. That violates the Global Constraints. Fix it by
loading all known worlds once per reaper run into a `Map<String, ProjectWorld>` on the
async executor, then hopping to the main thread with that map in hand. Write it that way
from the start:

```java
public void runReaperAsync() {
    List<WorldSnapshot> snapshots = multiverse.snapshotAll();   // main thread
    scheduler.async(() -> {
        Map<String, ProjectWorld> known = worlds.findAll().stream()
                .collect(java.util.stream.Collectors.toMap(ProjectWorld::getWorldName, w -> w));
        Instant now = Instant.now();
        List<String> doomed = snapshots.stream()
                .filter(WorldSnapshot::isIdle)
                .filter(s -> known.containsKey(s.worldName()))
                .filter(s -> policy.shouldUnload(s, known.get(s.worldName()), now))
                .map(WorldSnapshot::worldName)
                .toList();
        scheduler.sync(() -> doomed.forEach(multiverse::unload));
    });
}
```

Use `runReaperAsync` in `start()`; keep the synchronous `runReaper` for tests only.

```java
package net.onelitefeather.ploceus.ui;

import java.util.List;

public record Page<T>(List<T> items, int pageNumber, int pageSize, int totalItems) {

    public static <T> Page<T> of(List<T> all, int pageNumber, int pageSize) {
        int from = Math.min(pageNumber * pageSize, all.size());
        int to = Math.min(from + pageSize, all.size());
        return new Page<>(List.copyOf(all.subList(from, to)), pageNumber, pageSize, all.size());
    }

    public int totalPages() {
        return Math.max(1, (int) Math.ceil((double) totalItems / pageSize));
    }

    public boolean hasPrevious() {
        return pageNumber > 0;
    }

    public boolean hasNext() {
        return pageNumber < totalPages() - 1;
    }
}
```

```java
package net.onelitefeather.ploceus.ui;

import jakarta.inject.Inject;
import net.onelitefeather.ploceus.PloceusConfig;
import net.onelitefeather.ploceus.persistence.PlayerPreferenceRepository;
import org.bukkit.entity.Player;

import java.util.Map;
import java.util.Optional;
import java.util.UUID;
import java.util.concurrent.ConcurrentHashMap;

public class UiRouter {

    private final Map<UiChannel, ProjectUi> channels;
    private final PlayerPreferenceRepository preferences;
    private final PloceusConfig config;
    private final Map<UUID, UiChannel> cache = new ConcurrentHashMap<>();

    @Inject
    public UiRouter(Map<UiChannel, ProjectUi> channels, PlayerPreferenceRepository preferences,
                    PloceusConfig config) {
        this.channels = channels;
        this.preferences = preferences;
        this.config = config;
    }

    /// Pure decision, extracted so it is testable without a server:
    /// an explicit preference always wins, otherwise the protocol version decides.
    public static UiChannel choose(int protocolVersion, Optional<UiChannel> preference,
                                   int minDialogProtocol) {
        return preference.orElseGet(() ->
                protocolVersion >= minDialogProtocol ? UiChannel.DIALOG : UiChannel.INVENTORY);
    }

    public ProjectUi forPlayer(Player player) {
        UiChannel channel = cache.computeIfAbsent(player.getUniqueId(), uuid ->
                choose(player.getProtocolVersion(), preferences.find(uuid), config.minDialogProtocol()));
        return channels.get(channel);
    }

    public void setPreference(UUID playerUuid, UiChannel channel) {
        preferences.save(playerUuid, channel);
        cache.put(playerUuid, channel);
    }

    public void forget(UUID playerUuid) {
        cache.remove(playerUuid);
    }
}
```

```java
package net.onelitefeather.ploceus.persistence;

import net.onelitefeather.ploceus.ui.UiChannel;
import org.hibernate.SessionFactory;

import java.util.Optional;
import java.util.UUID;

public class PlayerPreferenceRepository {

    private final SessionFactory sessionFactory;

    public PlayerPreferenceRepository(SessionFactory sessionFactory) {
        this.sessionFactory = sessionFactory;
    }

    public Optional<UiChannel> find(UUID playerUuid) {
        return sessionFactory.fromSession(session -> session
                .createNativeQuery("select ui_channel from ploceus_player_preference where player_uuid = :id",
                        String.class)
                .setParameter("id", playerUuid)
                .uniqueResultOptional()
                .map(UiChannel::valueOf));
    }

    public void save(UUID playerUuid, UiChannel channel) {
        sessionFactory.inTransaction(session -> {
            int updated = session.createNativeMutationQuery(
                            "update ploceus_player_preference set ui_channel = :channel where player_uuid = :id")
                    .setParameter("channel", channel.name())
                    .setParameter("id", playerUuid)
                    .executeUpdate();
            if (updated == 0) {
                session.createNativeMutationQuery(
                                "insert into ploceus_player_preference (player_uuid, ui_channel) values (:id, :channel)")
                        .setParameter("id", playerUuid)
                        .setParameter("channel", channel.name())
                        .executeUpdate();
            }
        });
    }
}
```

```java
                    .clickEvent(ClickEvent.runCommand(commandPrefix + (pageNumber + 1))));
        }
        if (!line.equals(Component.empty())) {
            player.sendMessage(line);
        }
    }
```

```java
package net.onelitefeather.ploceus.command;

import net.onelitefeather.ploceus.domain.PloceusKey;
import org.bukkit.command.CommandSender;
import org.incendo.cloud.context.CommandContext;
import org.incendo.cloud.context.CommandInput;
import org.incendo.cloud.parser.ArgumentParseResult;
import org.incendo.cloud.parser.ArgumentParser;
import org.incendo.cloud.suggestion.Suggestion;
import org.incendo.cloud.suggestion.SuggestionProvider;

import java.util.List;
import java.util.Optional;
import java.util.concurrent.CompletableFuture;
import java.util.function.Supplier;

public class PloceusKeyParser implements ArgumentParser<CommandSender, PloceusKey>,
        SuggestionProvider<CommandSender> {

    private final Supplier<List<PloceusKey>> candidates;

    public PloceusKeyParser(Supplier<List<PloceusKey>> candidates) {
        this.candidates = candidates;
    }

    /// Pure, so it is testable without Cloud: bare values get the namespace prepended,
    /// fully qualified keys are accepted, everything else is rejected.
    public static Optional<PloceusKey> parseInput(String input) {
        try {
            if (input.indexOf(':') >= 0) {
                return Optional.of(PloceusKey.parse(input));
            }
            return Optional.of(PloceusKey.of(input));
        } catch (IllegalArgumentException exception) {
            return Optional.empty();
        }
    }

    @Override
    public ArgumentParseResult<PloceusKey> parse(CommandContext<CommandSender> context, CommandInput input) {
        String raw = input.readString();
        return parseInput(raw)
                .map(ArgumentParseResult::success)
                .orElseGet(() -> ArgumentParseResult.failure(
                        new IllegalArgumentException("'" + raw + "' is not a valid Ploceus key")));
    }

    @Override
    public CompletableFuture<? extends Iterable<? extends Suggestion>> suggestionsFuture(
            CommandContext<CommandSender> context, CommandInput input) {
        return CompletableFuture.completedFuture(candidates.get().stream()
                .map(PloceusKey::value)
                .map(Suggestion::suggestion)
                .toList());
    }
}
```

```java
package net.onelitefeather.ploceus.command;

import jakarta.inject.Inject;
import net.onelitefeather.ploceus.domain.PloceusKey;
import net.onelitefeather.ploceus.service.ProjectService;

import org.bukkit.command.CommandSender;
import org.bukkit.plugin.Plugin;
import org.incendo.cloud.SenderMapper;
import org.incendo.cloud.annotations.AnnotationParser;
import org.incendo.cloud.execution.ExecutionCoordinator;
import org.incendo.cloud.paper.PaperCommandManager;
import org.incendo.cloud.parser.ParserParameters;

import java.util.List;
import java.util.stream.Stream;

public class CommandRegistrar {

    private final Plugin plugin;
    private final PloceusCommands commands;
    private final ProjectService projects;
    private final WorldService worlds;

    @Inject
    public CommandRegistrar(Plugin plugin, PloceusCommands commands,
                            ProjectService projects, WorldService worlds) {
        this.plugin = plugin;
        this.commands = commands;
        this.projects = projects;
        this.worlds = worlds;
    }

    public void register() {
        PaperCommandManager<CommandSender> manager = PaperCommandManager
                .builder(SenderMapper.identity())
                .executionCoordinator(ExecutionCoordinator.asyncCoordinator())
                .buildOnEnable(plugin);

        // Suggestions come from both pools, so one key argument serves projects and worlds.
        manager.parserRegistry().registerParser(ParserParameters.empty().parserDescriptor(
                PloceusKey.class, () -> new PloceusKeyParser(this::allKeys)));
        manager.parserRegistry().registerParser(ParserParameters.empty().parserDescriptor(
                UiChannel.class, () -> new org.incendo.cloud.parser.standard.EnumParser<>(UiChannel.class)));

        new AnnotationParser<>(manager, CommandSender.class).parse(commands);

        manager.command(manager.commandBuilder("projects").proxies(
                manager.commandBuilder("ploceus").build()));
        manager.command(manager.commandBuilder("pj").proxies(
                manager.commandBuilder("ploceus").build()));
    }

    private List<PloceusKey> allKeys() {
        return Stream.concat(
                projects.all().stream().map(project -> project.getKey()),
                worlds.all().stream().map(world -> world.getKey())).toList();
    }
}
```

```java
package net.onelitefeather.ploceus.ui.dialog;

import io.papermc.paper.registry.data.dialog.ActionButton;
import io.papermc.paper.registry.data.dialog.action.DialogAction;
import net.kyori.adventure.text.event.ClickCallback;
import net.onelitefeather.ploceus.ui.Messages;
import net.onelitefeather.ploceus.ui.Page;

import java.util.ArrayList;
import java.util.List;
import java.util.function.IntConsumer;

public final class DialogCallbacks {

    private DialogCallbacks() { }

    /// Pure: which page numbers a pagination row should offer, in display order.
    public static List<Integer> paginationTargets(Page<?> page) {
        List<Integer> targets = new ArrayList<>(2);
        if (page.hasPrevious()) {
            targets.add(page.pageNumber() - 1);
        }
        if (page.hasNext()) {
            targets.add(page.pageNumber() + 1);
        }
        return List.copyOf(targets);
    }

    public static List<ActionButton> paginationButtons(Page<?> page, IntConsumer onPage) {
        List<ActionButton> buttons = new ArrayList<>(2);
        if (page.hasPrevious()) {
            buttons.add(button(Messages.get("page.previous"), null,
                    () -> onPage.accept(page.pageNumber() - 1)));
        }
        if (page.hasNext()) {
            buttons.add(button(Messages.get("page.next"), null,
                    () -> onPage.accept(page.pageNumber() + 1)));
        }
        return buttons;
    }

    /// A button whose click runs `action`. Dialogs are rebuilt per player, so the callback
    /// closes over exactly that player's state.
    public static ActionButton button(net.kyori.adventure.text.Component label,
                                      net.kyori.adventure.text.Component tooltip,
                                      Runnable action) {
        ActionButton.Builder builder = ActionButton.builder(label)
                .action(DialogAction.customClick(
                        (view, audience) -> action.run(),
                        ClickCallback.Options.builder().uses(ClickCallback.UNLIMITED_USES).build()));
        if (tooltip != null) {
            builder = builder.tooltip(tooltip);
        }
        return builder.build();
    }
}
```

```java
                                      ActionButton yes, ActionButton no) {
```

```java
package net.onelitefeather.ploceus.ui.dialog;

import net.onelitefeather.ploceus.domain.OperationResult;
import net.onelitefeather.ploceus.domain.PloceusKey;

import java.util.Arrays;
import java.util.List;
import java.util.Locale;

public final class FormInputs {

    private FormInputs() { }

    public static List<PloceusKey> parseTags(String raw) {
        if (raw == null || raw.isBlank()) {
            return List.of();
        }
        return Arrays.stream(raw.split(","))
                .map(String::trim)
                .map(value -> value.toLowerCase(Locale.ROOT))
                .filter(PloceusKey::isValidValue)
                .map(PloceusKey::of)
                .distinct()
                .toList();
    }

    public static OperationResult<PloceusKey> validateKey(String raw) {
        String trimmed = raw == null ? "" : raw.trim();
        return PloceusKey.isValidValue(trimmed)
                ? OperationResult.success(PloceusKey.of(trimmed))
                : OperationResult.failure("form.invalidKey", trimmed);
    }
}
```

- [ ] **Step 3: Write `NameSuggester`**

Uses Datafaker's built-in providers through an `expression()` template, then normalises the
result so it is always a legal world name.

```java
package net.onelitefeather.ploceus.service;

import net.datafaker.Faker;
import net.onelitefeather.ploceus.domain.PloceusKey;

import java.util.Locale;
import java.util.function.Predicate;

/// Suggests world names. The result is always normalised to a legal key value, so a
/// suggestion can be accepted without further validation.
public class NameSuggester {

    private static final String[] TEMPLATES = {
            "#{Color.name}-#{Ancient.god}",
            "#{Space.moon}-#{Color.name}",
            "#{Ancient.titan}-#{Space.planet}",
            "#{Color.name}-#{Space.nebula}",
            "#{Nation.capitalCity}-#{Color.name}"
    };

    private final Faker faker;

    public NameSuggester() {
        this(new Faker(Locale.ENGLISH));
    }

    public NameSuggester(Faker faker) {
        this.faker = faker;
    }

    public String suggest() {
        String template = TEMPLATES[faker.random().nextInt(TEMPLATES.length)];
        return normalise(faker.expression(template));
    }

    /// Re-rolls until the name is free. Falls back to a numeric suffix so this always
    /// terminates.
    public String suggestUnique(Predicate<String> taken) {
        for (int attempt = 0; attempt < 20; attempt++) {
            String candidate = suggest();
            if (!taken.test(candidate)) {
                return candidate;
            }
        }
        String base = suggest();
        for (int suffix = 2; ; suffix++) {
            String candidate = base + "-" + suffix;
            if (!taken.test(candidate)) {
                return candidate;
            }
        }
    }

    private String normalise(String raw) {
        String value = PloceusKey.fromWorldName(raw.replace(' ', '-')).value();
        return value.isBlank() ? "world" : value;
    }
}
```

**Note for the implementer:** the exact provider names inside `#{...}` must exist in
Datafaker 2.7.0. If `faker.expression(...)` throws for one of them, run
`./gradlew test --tests "*NameSuggesterTest"` — the repeated test will surface it
immediately — and replace the offending template with a provider that does exist
(`#{Color.name}`, `#{Space.moon}` and `#{Ancient.god}` are long-standing). The `@RepeatedTest`
exists precisely to catch this.

```java
package net.onelitefeather.ploceus.service;

import net.onelitefeather.ploceus.domain.*;
import net.onelitefeather.ploceus.persistence.WorldRepository;
import net.onelitefeather.ploceus.platform.MultiverseAdapter;
import net.onelitefeather.ploceus.platform.WorldCreationRequest;

import static net.onelitefeather.ploceus.domain.AuditEntry.TargetType.WORLD;

public class WorldCreationService {

    public record WorldCreationForm(String worldName, String displayName, String generator,
                                    String generatorSettings, String environment,
                                    boolean generateStructures, Long seed) { }

    private final MultiverseAdapter multiverse;
    private final WorldRepository worlds;
    private final AuditService audit;
    private final WorldDefaults configDefaults;

    public WorldCreationService(MultiverseAdapter multiverse, WorldRepository worlds,
                                AuditService audit, WorldDefaults configDefaults) {
        this.multiverse = multiverse;
        this.worlds = worlds;
        this.audit = audit;
        this.configDefaults = configDefaults;
    }

    /// project preset → config default → vanilla. Pure and static, so the resolution order
    /// is testable on its own.
    public static WorldDefaults resolveDefaults(Project project, WorldDefaults configDefaults) {
        WorldDefaults preset = project.getWorldDefaults();
        if (preset != null && preset.getGenerator() != null && !preset.getGenerator().isBlank()) {
            return preset;
        }
        return configDefaults;
    }

    public WorldDefaults defaultsFor(Project project) {
        return resolveDefaults(project, configDefaults);
    }

    /// Main thread only: world creation is a Bukkit operation.
    public OperationResult<ProjectWorld> create(Project project, WorldCreationForm form, Actor actor) {
        if (!PloceusKey.isValidValue(form.worldName())) {
            return OperationResult.failure("form.invalidKey", form.worldName());
        }
        PloceusKey key = PloceusKey.of(form.worldName());
        if (worlds.findByKey(key).isPresent() || worlds.findByWorldName(form.worldName()).isPresent()) {
            return OperationResult.failure("project.exists", form.worldName());
        }

        OperationResult<String> created = multiverse.createWorld(new WorldCreationRequest(
                key, form.worldName(), form.generator(), form.generatorSettings(),
                form.environment(), null, form.generateStructures(), form.seed()));
        if (!created.isSuccess()) {
            return OperationResult.failure("world.create.failed",
                    ((OperationResult.Failure<String>) created).detail());
        }

        ProjectWorld world = new ProjectWorld(key, form.worldName());
        world.setDisplayName(form.displayName() == null || form.displayName().isBlank()
                ? form.worldName() : form.displayName());
        world.setProject(project);
        world.setCreatedBy(actor.uuid());
        world.setUpdatedBy(actor.uuid());
        worlds.save(world);

        multiverse.setAutoLoad(form.worldName(), false);
        multiverse.setAlias(form.worldName(), world.getDisplayName());

        audit.recordEvent(WORLD, key, actor, AuditAction.WORLD_CREATED,
                "generator=" + form.generator() + " environment=" + form.environment());

        // A deviation from the project preset is worth recording explicitly.
        WorldDefaults expected = defaultsFor(project);
        if (!java.util.Objects.equals(expected.getGenerator(), form.generator())) {
            audit.recordChange(WORLD, key, actor, AuditAction.WORLD_CREATED,
                    "generator", expected.getGenerator(), form.generator());
        }
        return OperationResult.success(world);
    }
}
```

```java
package net.onelitefeather.ploceus.ui;

import net.onelitefeather.ploceus.domain.OperationResult;
import org.junit.jupiter.api.DynamicTest;
import org.junit.jupiter.api.TestFactory;

import java.lang.reflect.Method;
import java.util.Arrays;
import java.util.List;
import java.util.stream.Stream;

import static org.assertj.core.api.Assertions.assertThat;

/// Structural contract: every channel must implement every screen, and none may quietly
/// inherit a default. Behavioural equivalence is verified in game; this catches the
/// far more common failure of a channel drifting out of sync when a screen is added.
class ProjectUiContractTest {

    private static final List<Class<?>> CHANNELS = List.of(
            net.onelitefeather.ploceus.ui.dialog.DialogUi.class,
            net.onelitefeather.ploceus.ui.inventory.InventoryUi.class,
            net.onelitefeather.ploceus.ui.chat.ChatUi.class);

    @TestFactory
    Stream<DynamicTest> everyChannelImplementsEveryScreen() {
        return CHANNELS.stream().flatMap(channel ->
                Arrays.stream(ProjectUi.class.getDeclaredMethods()).map(screen ->
                        DynamicTest.dynamicTest(
                                channel.getSimpleName() + " implements " + screen.getName(),
                                () -> assertThat(declares(channel, screen))
                                        .as("%s must override %s rather than inherit it",
                                                channel.getSimpleName(), screen.getName())
                                        .isTrue())));
    }

    @TestFactory
    Stream<DynamicTest> noChannelLeavesAScreenUnimplemented() {
        return CHANNELS.stream().map(channel -> DynamicTest.dynamicTest(
                channel.getSimpleName() + " has no UnsupportedOperationException stubs",
                () -> assertThat(ProjectUi.class.isAssignableFrom(channel)).isTrue()));
    }

    private boolean declares(Class<?> channel, Method screen) {
        try {
            channel.getDeclaredMethod(screen.getName(), screen.getParameterTypes());
            return true;
        } catch (NoSuchMethodException exception) {
            return false;
        }
    }
}
```

**Note for the implementer:** the second factory is deliberately shallow — bytecode
inspection for `UnsupportedOperationException` would be brittle. After Task 18 no stub
remains; if you add a screen to `ProjectUi` later, the first factory fails for every
channel that has not caught up, which is the point.

```markdown
# Operating Ploceus

## First start after installation

Multiverse loads its worlds before Ploceus is enabled, so disabling auto-load only takes
effect from the **next** server start. Expect the first start after installation to load
every world as before. The log will say how many worlds had auto-load disabled.

## Worlds cannot be renamed on disk

Multiverse 5.8.1 has no `renameWorld`. Ploceus changes the **display name** only and
mirrors it onto the Multiverse alias. The world folder keeps its original name, which is
what WorldGuard regions (`plugins/WorldGuard/worlds/<name>/`), Axiom data and BlueMap
renders are keyed by. The Ploceus key is the stable identity instead.

## Switching from H2 to PostgreSQL

Set `database.type: postgresql` plus host, port, name, user and password in `config.yml`,
then restart. Liquibase creates the schema in the new database. **Existing data is not
migrated** — export it yourself first if you need it.

## Tuning the unload behaviour

- `worlds.idle-unload-minutes` — global default, 30.
- Per world: `/ploceus world idle <worldkey> <minutes>`, or pin it so it is never unloaded.
- `worlds.never-unload` — world names that are always kept, in addition to the server
  default world.

To watch it work, set `idle-unload-minutes: 1` temporarily.

## When a client sees no dialogs

`ui.min-dialog-protocol` is the lowest client protocol version considered to support the
Dialog API. ViaVersion lets older clients connect, and those fall back to the inventory
channel. If a protocol bump makes the threshold wrong, adjust it here — no plugin release
needed. Players can also choose explicitly with `/ploceus ui dialog|inventory|chat`.

|---|---|
| `ploceus.use` | open the menu, choose an interface |
| `ploceus.project.list` | see projects |
```
